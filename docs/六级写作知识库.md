# 六级写作关联阅读模块

更新日期：2026-11-12

## 使用与范围

在首页的学习区域点击“六级写作知识库”，进入同一页面中的作文目录、作文正文和句型讲解。点击英文标记进入句型；句型下的每条示例返回一次明确的出现位置。作文默认折叠，定位会打开全部折叠祖先并聚焦、高亮目标。

首版含一篇自编技术演示作文、三个句型、四个英文片段，其中一个句型使用两次，另有嵌套折叠。演示不是真题，也不代表个人学习进度。普通学习记录、封面和技能树入口保留。学习状态仍在 Markdown 中人工维护。

## 内容契约

- 作文：src/content/essays/*.md；句型：src/content/patterns/*.md。
- frontmatter 字段：stableId、title、description、order、demo。stableId 分别以 essay-、pattern- 开头，使用小写字母、数字、连字符。模板位于 docs/templates。
- 作文片段格式如下，id 为永久分配的编号，data-location 是可更新的位置说明：

```html
<a id="occ-your-essay-001" data-pattern-id="pattern-your-pattern" data-location="开头段第二句" href="#pattern-your-pattern">English excerpt</a>
```

正文标记由助手生成，你无需手写。id 在修改标题、措辞、段落顺序时保持不变；不同出现位置各有一个 ID。同一片段只关联一个句型，不嵌套链接。句型侧的示例列表从标记自动提取，不手工补返回链接。只使用经审阅的本地 Markdown；外部资料先整理，不直接引入未经审查的 HTML。

关联索引在构建时生成，不维护第二份可编辑关联 JSON。data/writing-ids.json 是身份登记表，只记录稳定 ID 的类型、归属和生命周期，不复制例句或示例列表。

## ID 新增与删除

新增作文、句型、片段时，在登记表添加同名条目，state 为 active。essay 与 pattern 的 owner 为自身 ID；occ 的 owner 为作文 ID。

删除时不移除登记条目：将 state 改为 retired 并写入 reason。页面会生成同 ID 的“该示例已调整”说明及目录入口。退休 ID 不重新使用；旧记录不更换归属。构建会对照当前 Git HEAD 中的登记表检查删除或重新分配。

登记表不可自动辨认“语义上是否仍为同一片段”，执行者仍需审核；没有 Git 历史的源码副本仅能检查当前登记一致性。对外发布前还应保持可靠的已发布版本记录。

## 检查与生成

```powershell
npm.cmd run check:writing
npm.cmd run update:notes
```

update:notes 会运行首页交互测试、知识库测试、静态构建及单文件导出。构建过程还会检查最终 DOM 的 ID、所有本页锚点、每个片段唯一且正确的返回链接，以及历史登记表。检查失败不会写出新的成功预览；之前的预览可能仍存在，应以命令成功为准。

新增 HTML 解析器 parse5 和 Astro 官方 Markdown 处理器，用于片段校验和文档标题命名空间。依赖版本由锁文件固定。普通 Markdown 标题在不同文档间自动隔离，永久深链接请使用明确登记的 essay/pattern/occ ID，不依赖自动标题 ID。

## 导航与离线

使用原生 hash 和浏览器历史，不引入客户端路由。不拦截修饰键、新标签页或下载链接。知识库不受学习状态筛选影响；知识库定位使用即时滚动，不受首页平滑滚动影响。

outputs/首页预览.html 包含全文、样式、脚本及图片，无需额外 JSON 请求。离线链接在同一 HTML 内生效；换设备需要传递文件，不能直接分享本机文件路径。关闭脚本时全文仍在文件中，可手动展开；自动展开定位不再保证。
