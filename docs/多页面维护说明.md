# 首页摘要与多页面维护

更新日期：2026-11-12

首页保留封面，每类最多三条摘要，完整正文只在详情页出现。项目按 order，学习按 updated 倒序、order、文件 ID 排序。首页不显示完整知识库或技能图，不自动添加阅读量、评论等数据。

项目列表 /projects/；项目详情 /projects/{文件ID}/；学习列表 /learning/；笔记详情 /learning/notes/{文件ID}/；知识库 /learning/cet6/；技能树占位 /skill-tree/。标题改动不改变地址，重命名文件会改变地址。Markdown 内容与 ID 登记保持原维护约定。

左上角菜单打开分类页面，默认当前标签页。详情提供返回分类和首页入口。学习状态筛选只在学习列表中提供。旧首页 #writing-library、#essay-*、#pattern-*、#occ-* 会转到新知识库页面的同一锚点，普通分类锚点仍保留。

## 本地使用

运行 npm.cmd run update:notes，双击 outputs/网站预览/index.html。旧 outputs/首页预览.html 是兼容入口。移动、备份或分享生成网站时携带完整 网站预览 文件夹，不能只复制某个 HTML。

导出器生成相对的 index.html 链接、内联样式与普通脚本，资源随文件夹输出；不依赖运行时 API、模块加载或远程字体。每次重新生成只清理明确的 outputs/网站预览 生成目录，不要在其中手动保存原创内容。

## 本轮验证

15 项自动测试通过；静态构建生成 9 页，离线导出检查全部页面链接与片段目标。浏览器 HTTP 检查了首页摘要、项目详情、学习筛选、知识库迁移与旧锚点跳转、320px 无横向溢出、手机扇形菜单进入技能树页。错误日志为空。

浏览器工具不支持 file:// 直接打开，未以其他方式绕过；离线直接打开需要人工验收：

1. 双击新首页，点项目标题进入详情，再返回项目列表及首页。
2. 在学习列表切换状态，打开一条笔记并返回。
3. 在知识库点嵌套示例，确认展开和高亮；点击原句到句型，再返回。
4. 断网重复以上操作，确认封面、背景与脚本可用。
