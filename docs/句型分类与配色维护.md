# 句型分类荧光笔与悬浮图例

更新日期：2026-11-12

## 已实现

正文的棕色虚线替换为 0.22em 分类色实线粗标注，附可见小号分类简称。句型卡片、示例列表、图例使用同一分类映射。当前为三类演示：背景引入、并列递进、总结收束；不代表正式五类或个人掌握程度。

知识库右侧统一为 220px 阅读辅助面板，分类说明默认展开，作文目录为内部折叠区。大于 1100px 使用 sticky，顶部 110px，最大高度为视口减 134px，超出内部滚动；1100px 及以下移到正文前并默认收起。没有浮窗或分类筛选。

定位高亮保持到 hash 改变，使用独立浅中性底色与轮廓，不覆盖分类底线。原 occurrence、essay、pattern ID 和双向链接不变。

## 数据与更新

唯一配置为 data/writing-categories.json，包含 palette、categories、assignments。分类记录包含 id、label、shortLabel、scope（demo/main）、order、state（active/retired）。demo 和 main 各自领取颜色，不互相占用。原十种色值保留，真实显示需按反馈继续评估。

句型 Markdown 必填 categoryId；作文仍只引用 data-pattern-id，不手写分类与颜色。构建自动添加标注及简称，不修改原作文 Markdown。

新增分类时仅在 categories 中添加稳定 ID 及元信息；执行 npm.cmd run sync:categories 或 npm.cmd run update:notes。工具按分类 ID 排序领取本作用域最靠前的未用令牌，写入 assignments；构建与浏览器不分配颜色。重复同步不改变文件或颜色。

删除类别先迁移仍引用它的句型，再标为 retired，保留分类及原令牌，不回收。重命名、排序不改变颜色；改变句型 categoryId 属于明确的重新分类。已提交版本的分类 ID、scope、已分配令牌、已有色值受到历史校验保护，不能删除或重用。没有 Git 历史的副本只能验证当前一致性。

十色耗尽时 assignments 为 null，显示中性标注和“待配色”，同步工具打印警告。补充新的 palette 令牌后再次同步，按稳定 ID 顺序分配。未知分类、退休分类引用、重复分配、非法令牌及历史改色阻止构建。

同步使用排他锁与临时文件替换；并发运行会拒绝第二个操作。异常中断若残留锁，先确认没有进程运行再人工处理。锁和临时文件已被 Git 忽略。

## 检查与证据

- 七项分类自动测试通过：五类/第六类、幂等及改名重排、退休不回收、第十一类待配色与扩容、独立作用域、错误数据、历史保护和未知引用。
- 现有五项动态文字、十项知识库测试通过，总计 22 项。
- 实际文件同步的字节和修改时间保持不变；预置锁后第二个同步操作被拒绝，测试锁已删除。
- 构建检查每个渲染片段的分类 ID 与实际色值，防止缓存或模板造成串色；分类配置作为 Markdown 处理器输入，变化后重新渲染。
- 浏览器 1440×900：四个片段按类别显示，重复句型色值一致，下划线为 3.08px，右侧图例 220px、top 110px。
- 原句进入句型、返回嵌套原句、刷新后焦点与折叠状态通过；320px 无横向溢出，面板默认收起且键盘可展开。
- 1440×430：面板被限制为约 296px，overflow 为 auto；浏览器错误日志为空。
- 当前仍使用演示资料；离线直接打开、真实设备触控、200% 缩放、高对比度与读屏专项未实测，不能标为全部兼容。
