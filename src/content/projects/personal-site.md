## 关于这个项目

这个网站本身，就是这里的第一个项目。以绘梨衣花田落日图作为封面，用“欢迎来到我的世界”迎接每一次访问。

### 已经实现

- 全屏封面、循环打字欢迎语和左上角扇形导航。
- 独立的绘梨衣正文背景，配合模糊、柔和遮罩和毛玻璃卡片。
- 项目详情展开、学习记录状态筛选和手机布局。
- 用 Markdown 管理内容，导出可以单独打开的首页 HTML。
- GitHub 源码同步，以及欢迎语循环、暂停恢复和减少动态效果的逻辑检查。

### 接下来

逐步填入更多真实项目和学习笔记，再按实际使用反馈调整页面。算法技能树目前只保留入口，尚未实现节点与进度管理。

本站已通过 GitHub Pages 上线。项目与学习记录随 main 分支的更新自动发布。
